# Keyfor IA : Atendimento Humanizado 24/7 com Inteligencia Artificial

Landing page corporativa de alta conversao para a **Keyfor IA**, desenvolvida com estetica clean tech moderna e editorial.

## Tecnologias

- **Vite** + **React**
- **Tailwind CSS**
- **Lucide Icons**
- Tipografia: **Plus Jakarta Sans** & **Instrument Serif**

## Como Rodar Localmente

```bash
npm install
npm run dev
```
